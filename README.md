# Student Management System

A simple console-based Student Management System developed using C#.

## Features

- Add Student
- View Student
- Exit
- User-friendly console menu

## Technologies Used

- C#
- .NET 10
- Visual Studio
- Git & GitHub

## How to Run

1. Clone this repository.
2. Open the project in Visual Studio.
3. Build the project.
4. Run the application.

## Project Structure

- `Program.cs` - Main C# program
- `Project1.csproj` - Project configuration
- `.gitignore` - Ignores build files such as `bin` and `obj`
